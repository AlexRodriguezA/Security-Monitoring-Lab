# Evidence Screenshots

This directory contains screenshots captured from the Windows Security Event Log to validate authentication and process execution telemetry generated in this lab.

The screenshots in this folder demonstrate:
- Successful authentication events (Event ID 4624)
- Failed authentication events (Event ID 4625)
- Process creation telemetry (Event ID 4688)

Each screenshot includes relevant security fields such as timestamp, hostname, account name, logon type, and process details where applicable.
